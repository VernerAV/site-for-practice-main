# README – Веб-сайт ГБУ «Жилищник района Строгино» с модулем автоматизации обращений

Этот проект представляет собой адаптивный веб-сайт для Государственного бюджетного учреждения города Москвы «Жилищник района Строгино». Сайт автоматизирует приём и обработку обращений граждан, предоставляет информационные разделы (новости, платные услуги, контакты), личный кабинет жителя и панель администратора.

## Основные возможности

### Для всех посетителей (гостей)
- Просмотр новостей (слайдер на главной + отдельная страница новостей).
- Просмотр прайс-листа платных услуг (таблица с поиском).
- Контактная информация и форма подачи заявки (без регистрации).
- Адаптивный дизайн для компьютеров, планшетов и телефонов (ширина от 320 пикселей).
- Версия для слабовидящих (высокий контраст, увеличение шрифта).

### Для авторизованных жителей
- Личный кабинет с редактированием профиля (ФИО, адрес, телефон, дата рождения).
- История своих заявок с отображением статуса и ответов администратора.
- Создание новой заявки с выбором категории и предпочтительной датой.
- Уведомления об изменении статуса.

### Для администратора
- Полное управление новостями (CRUD).
- Управление услугами (прайс-лист).
- Управление пользователями (добавление, редактирование, блокировка, назначение ролей).
- Обработка заявок и сообщений (фильтрация, поиск, массовое удаление, ответы).
- Статистика по обращениям.
- Автоматическое распределение заявок по категориям/исполнителям.
- Журнал изменений.

### Мобильная версия
- Гамбургер-меню (выезжает справа при ширине ≤768px).
- Поиск под шапкой.
- Таблицы превращаются в карточки с подписями (data-label).
- Слайдер новостей на мобильных переключается в ручной режим (автопрокрутка отключена).

## Установка и запуск

### Требования
- Веб-сервер Apache с поддержкой PHP 7.4+
- MySQL 5.7+
- Расширения PHP: PDO MySQL, session, json, fileinfo

### Инструкция

1. **Клонировать репозиторий**
   ```bash
   git clone https://github.com/VernerAV/site-for-practice-main.git
   ```

2. **Создать базу данных**  
   Импортировать файл `database.sql` (если есть в репозитории; при отсутствии – создать таблицы по описанию в отчёте).

3. **Настроить подключение к БД**  
   Скопировать `includes/config.example.php` в `includes/config.php` и указать свои параметры:
   ```php
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'имя_бд');
   define('DB_USER', 'пользователь');
   define('DB_PASS', 'пароль');
   ```

4. **Настройка веб-сервера**  
   Поместить проект в корень локального сервера (например, `htdocs` для XAMPP).  
   Убедиться, что модуль `mod_rewrite` включён (если используются ЧПУ).

5. **Права на папки**  
   Папка `uploads/news/` должна быть доступна для записи (chmod 755).

6. **Запуск**  
   Открыть в браузере `http://localhost/site-for-practice-main/`.

## Руководство пользователя

Сайт ГБУ «Жилищник района Строгино» предоставляет различные возможности для четырёх категорий пользователей: гостей (неавторизованных), жителей (авторизованных), сотрудников и администраторов. Ниже описаны функции и инструкции для каждой группы.

---

## 1. Неавторизованный пользователь (гость)

Гость может посещать сайт без регистрации. Ему доступны информационные разделы и форма подачи обращения.

### Основные возможности

- Просмотр новостей (главная страница, раздел «Новости», детальная страница новости).
- Ознакомление с прайс-листом платных услуг (раздел «Прайс-лист»).
- Изучение информации о компании, контактов, графика приёма (разделы «О компании», «Контакты»).
- Поиск по сайту (строка поиска в шапке).
- Подача заявки или обращения через форму на странице `contact.php`.
- Проверка статуса ранее поданной заявки по номеру (страница `check_status.php`).

### Как подать заявку без регистрации

1. Перейдите в меню и выберите **«Оставить заявку»** или откройте страницу `contact.php`.
2. В пошаговой форме укажите:
   - тип обращения (заявка или обращение);
   - категорию;
   - срочность, объём работ, готовность к работе (если это заявка);
   - адрес объекта (улица, дом, подъезд, квартира и т.д.);
   - свои контакты (ФИО, email, телефон);
   - подробное описание проблемы.
3. Проверьте введённые данные на последнем шаге и нажмите **«Отправить»**.
4. После отправки вы получите номер заявки, который нужно сохранить.

### Как проверить статус заявки

- Перейдите на страницу **«Проверить статус»** (или откройте `check_status.php`).
- Введите номер заявки (например, `123`).
- Нажмите **«Проверить»** — отобразится текущий статус, дата создания, ответы администратора.

### Что ещё полезно знать

- Все формы на сайте защищены, данные передаются по HTTPS.
- Если вы хотите отслеживать все свои заявки в одном месте, рекомендуется зарегистрироваться.

## 2. Авторизованный пользователь (житель)

После регистрации и входа в личный кабинет вам открывается дополнительный функционал.

### Регистрация и вход

- Для регистрации перейдите по ссылке **«Регистрация»** на странице входа (`login.php`).
- Заполните email, пароль (минимум 6 символов), подтверждение пароля, а также имя, фамилию и телефон (по желанию).
- После успешной регистрации вы будете перенаправлены на страницу входа.
- Войдите, используя свой email и пароль.

### Личный кабинет (`user.php`)

После входа вы попадаете в личный кабинет с двумя вкладками:

#### Вкладка «Профиль»

- Здесь отображаются ваши контактные данные (email, ФИО, телефон, дата рождения, адрес).
- Вы можете отредактировать их и сохранить изменения кнопкой **«Сохранить изменения»**.
- Поля «Улица и дом», «Квартира» являются обязательными – они используются при создании заявок.

#### Вкладка «Мои заявки»

- Здесь отображаются все ваши заявки, созданные после авторизации или гостем (по email).
- Доступны фильтры по статусу: **Все**, **Новые**, **В работе**, **Выполненные**.
- Можно осуществлять поиск по теме/сообщению и фильтровать по дате (быстрые фильтры: Сегодня, Завтра, Эта неделя, Этот месяц).
- Каждая заявка отображается в виде карточки с номером, статусом, датой, текстом и ответом администратора (если есть).
- Кнопка **«Подробнее»** открывает модальное окно с полной информацией.
- Если заявка не прочитана, можно отметить её как прочитанную.

### Создание заявки из личного кабинета

- Находясь в личном кабинете, вы можете создать новую заявку, перейдя по ссылке **«Оставить заявку»** (или через `contact.php`). При этом поля «ФИО», «Email» и «Адрес» будут подставлены автоматически из профиля.

### Выход из системы

- Для завершения сеанса нажмите **«Выйти»** в верхнем меню.

## 3. Сотрудник (исполнитель / диспетчер / модератор)

Сотрудники получают доступ к внутренней панели для обработки назначенных им заявок. Вход осуществляется через общую форму логина.

### Вход в панель сотрудника

- На странице входа введите свои учётные данные (email и пароль), выданные администратором.
- После входа вы будете перенаправлены на страницу `employee.php` (личный кабинет сотрудника).

### Личный кабинет сотрудника (`employee.php`)

#### Основные элементы

- Шапка с вашим именем, должностью и табельным номером.
- Вкладки: **Все**, **Новые**, **В работе**, **Выполненные** — для быстрой фильтрации назначенных вам заявок.
- Панель фильтров: поиск по теме/сообщению, выбор периода дат.
- Список заявок в виде карточек.

#### Действия с заявками

| Действие | Описание | Условие |
|----------|----------|---------|
| **Взять в работу** | Изменяет статус на «В работе» | Заявка имеет статус «Новая» |
| **Выполнить** | Изменяет статус на «Выполнена» | Заявка имеет статус «В работе» |
| **Вернуть** | Возвращает заявку администратору для переназначения | Любой статус, кроме «Выполнена» |
| **Ответить** | Отправляет ответ пользователю, заявка становится «Выполненной» | Любой статус, кроме «Выполнена» (обычно после «В работе») |

#### Просмотр деталей

- Каждая карточка заявки содержит тему, текст сообщения, дату создания, дату назначения, а также ответ администратора (если имеется).

### Примечания

- Если вы администратор, вам также доступна страница `admin.php` для полного управления сайтом.
- Для выхода из системы используйте кнопку **«Выйти»** в шапке.

## 4. Администратор

Администратор имеет полный доступ ко всем функциям сайта, включая управление контентом, пользователями и заявками.

### Вход в панель администратора

- Войдите в систему с учётной записью администратора (роль `admin`).
- После входа вы будете автоматически перенаправлены на страницу `admin.php`, либо нажмите ссылку **«Панель администратора»** в верхнем меню.

### Структура панели администратора

Панель состоит из бокового меню с разделами:

- **Новости** — управление новостями.
- **Цены** — управление прайс-листом услуг.
- **Заявки** — обработка всех заявок.
- **Сотрудники** — управление учётными записями сотрудников.

#### Раздел «Новости»

- Добавление новости: нажмите **«➕ Добавить новость»**, заполните заголовок, описание, загрузите изображение (опционально), сохраните.
- Редактирование: нажмите на иконку карандаша в карточке новости, измените поля и сохраните.
- Удаление: нажмите на иконку корзины, подтвердите удаление.

#### Раздел «Цены»

- Добавление услуги: нажмите **«➕ Добавить услугу»**, укажите название, описание, цену, единицу измерения, сохраните.
- Редактирование и удаление аналогично новостям.

#### Раздел «Заявки»

- Отображается таблица всех заявок с фильтрами:
  - по статусу (Все, Новые, В работе, Выполненные) — вкладки над таблицей;
  - по отделу, дате, назначению (назначенные/неназначенные) — дополнительные фильтры.
- Для каждой заявки доступны действия:
  - **Просмотр** (👁️) — открывает подробную информацию;
  - **Редактирование** (✏️) — пока не реализовано (заглушка);
  - **Удаление** (🗑️) — удалить одиночную заявку (с подтверждением);
  - **Назначение** — через выпадающий список в столбце «Назначен» можно выбрать сотрудника (с учётом его загрузки) и нажать «Назначить».
- Возможно массовое удаление: отметьте чекбоксы нужных заявок и нажмите кнопку **«🗑️ Удалить выбранные»**.

#### Раздел «Сотрудники»

- Отображается список сотрудников с их данными (ФИО, email, телефон, должность, отдел, роль).
- Добавление сотрудника: нажмите **«➕ Добавить сотрудника»**, заполните форму (email, пароль, ФИО, отдел, должность, роль).
- Редактирование: нажмите на карандаш, измените данные, сохраните.
- Удаление: нажмите на корзину, подтвердите удаление.

### Дополнительные возможности

- В шапке панели отображается количество новых непрочитанных заявок (красный бейдж).
- Администратор также может просматривать заявки, назначенные на себя, через страницу `employee.php`, если его роль позволяет.
